# Histórias de Usuário

## HU01 — Encontrar treino adequado
**Como** aluno
**Quero** visualizar e filtrar treinos por objetivo, nível e duração
**Para** escolher uma opção compatível com minha rotina.

### Critérios de aceitação
- o catálogo deve exibir os treinos disponíveis;
- o aluno deve poder aplicar filtros;
- o resultado deve refletir os filtros selecionados.

## HU02 — Ver detalhes antes de iniciar
**Como** aluno
**Quero** visualizar os detalhes de um treino
**Para** entender se ele atende minha necessidade antes de começar.

### Critérios de aceitação
- o treino deve exibir título, objetivo, nível e duração;
- o formato do conteúdo deve estar identificado;
- o aluno deve conseguir iniciar o treino a partir da tela de detalhes.

## HU03 — Realizar treino guiado
**Como** aluno
**Quero** seguir treinos com vídeo, link externo ou texto
**Para** conseguir treinar em casa com orientação.

### Critérios de aceitação
- o sistema deve suportar os formatos definidos;
- o conteúdo deve ficar acessível durante a sessão;
- o aluno deve conseguir concluir o treino ao final.

## HU04 — Acompanhar progresso
**Como** aluno
**Quero** visualizar meu histórico de treinos
**Para** acompanhar minha constância e evolução.

### Critérios de aceitação
- o sistema deve registrar treinos concluídos;
- o histórico deve listar sessões anteriores;
- o aluno deve conseguir consultar seus registros.

## HU05 — Publicar treinos
**Como** instrutor
**Quero** cadastrar e publicar treinos
**Para** disponibilizar conteúdo organizado para os alunos.

### Critérios de aceitação
- o cadastro deve aceitar vídeo, link ou texto;
- o treino deve exigir dados mínimos obrigatórios;
- apenas usuários autorizados devem publicar conteúdo.

## HU06 — Manter catálogo organizado
**Como** administrador
**Quero** padronizar categorias e informações mínimas
**Para** manter a plataforma consistente e fácil de usar.

### Critérios de aceitação
- conteúdos incompletos não devem ser publicados;
- categorias devem estar disponíveis para classificação;
- a organização do catálogo deve facilitar descoberta e manutenção.
