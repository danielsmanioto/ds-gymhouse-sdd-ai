# Requisitos Funcionais

## RF01 — Cadastro de usuário
O sistema deve permitir o cadastro de usuários alunos.

## RF02 — Autenticação
O sistema deve permitir login de usuários cadastrados.

## RF03 — Catálogo de treinos
O sistema deve listar os treinos disponíveis para o aluno.

## RF04 — Filtragem de treinos
O sistema deve permitir filtrar treinos por objetivo, nível, duração e formato.

## RF05 — Visualização de detalhes do treino
O sistema deve exibir informações detalhadas do treino antes da execução.

## RF06 — Execução de treino guiado
O sistema deve permitir que o aluno realize um treino usando vídeo, link externo ou conteúdo textual.

## RF07 — Registro de conclusão
O sistema deve permitir registrar a conclusão de um treino pelo aluno.

## RF08 — Histórico de treinos
O sistema deve exibir o histórico de treinos concluídos pelo aluno.

## RF09 — Cadastro de conteúdo
O sistema deve permitir que instrutores ou administradores cadastrem novos treinos.

## RF10 — Edição de conteúdo
O sistema deve permitir atualizar treinos já cadastrados.

## RF11 — Publicação de treino
O sistema deve permitir publicar um treino após validação dos dados mínimos.

## RF12 — Organização por categorias
O sistema deve permitir classificar treinos por categoria, objetivo ou nível.
