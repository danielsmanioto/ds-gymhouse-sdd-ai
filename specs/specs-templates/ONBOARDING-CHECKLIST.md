# Onboarding Checklist — SDD Template

Use esta lista quando iniciar um novo projeto com os templates.

## Preparação

- [ ] Copiei os templates para o novo projeto.
- [ ] Defini o nome do projeto e domínio.
- [ ] Substituí placeholders `{{...}}` iniciais.

## Base mínima

- [ ] Visão do produto preenchida.
- [ ] Persona principal definida.
- [ ] Jornada principal definida.
- [ ] Requisitos funcionais iniciais definidos.
- [ ] Histórias de usuário iniciais definidas.
- [ ] Feature crítica detalhada.
- [ ] Diagrama de contexto criado.

## Qualidade

- [ ] RF e HU possuem rastreabilidade na feature crítica.
- [ ] Critérios de aceitação são verificáveis.
- [ ] Regras de negócio estão explícitas.
- [ ] Não há placeholders pendentes no pacote mínimo.

## Pronto para execução

- [ ] Backlog inicial priorizado.
- [ ] Primeira entrega incremental definida.
- [ ] Time alinhado com o fluxo SDD.
