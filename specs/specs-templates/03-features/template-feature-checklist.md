# Checklist de Qualidade da Feature Spec

Use esta checklist antes de considerar uma spec pronta.

## Clareza

- [ ] O objetivo da feature está explícito.
- [ ] O valor de negócio está descrito.
- [ ] Os atores envolvidos foram identificados.

## Regras e fluxos

- [ ] Existem regras de negócio claras.
- [ ] O fluxo principal está completo.
- [ ] Existem fluxos alternativos quando necessário.
- [ ] Exceções relevantes foram cobertas.

## Contratos e validações

- [ ] Entradas e saídas estão definidas.
- [ ] Validações mínimas estão listadas.
- [ ] Critérios de aceitação são verificáveis.

## Rastreabilidade

- [ ] A spec referencia requisitos funcionais.
- [ ] A spec referencia histórias de usuário.
- [ ] A feature está consistente com discovery e visão do produto.
