# Regras de Negócio Iniciais

## Conteúdo de treino

- Todo treino deve possuir título.
- Todo treino deve possuir pelo menos um objetivo principal.
- Todo treino deve informar nível sugerido.
- Todo treino deve informar duração estimada.
- Todo treino deve possuir um formato de conteúdo válido: vídeo interno, link externo ou texto.

## Publicação

- Apenas perfis autorizados podem cadastrar ou publicar treinos.
- Um treino só pode ser publicado se contiver os dados mínimos obrigatórios.
- Conteúdos devem estar vinculados a uma categoria ou classificação.

## Consumo do treino

- O aluno deve conseguir visualizar os detalhes antes de iniciar o treino.
- Um treino concluído deve poder ser registrado no histórico do aluno.
- O histórico deve considerar somente treinos finalizados.

## Organização do sistema

- Treinos devem poder ser filtrados por objetivo, nível e duração.
- O catálogo deve manter uma organização consistente para facilitar busca e descoberta.
