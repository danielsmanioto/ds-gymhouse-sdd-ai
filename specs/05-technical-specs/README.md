# 05 — Technical Specs

Esta etapa detalha contratos técnicos derivados das specs funcionais.

## Conteúdo inicial

- `api-contracts-v1.md`: contratos de API da primeira versão.
- `openapi-v1.yaml`: especificação OpenAPI 3.0 da v1.
- `postman-collection-v1.json`: coleção Postman v2.1.
- `postman-environment-local.json`: environment local para testes.

## Observação

A coleção Postman já inclui testes básicos por request (status code + validações mínimas de payload).

## Objetivo da etapa

Transformar requisitos e features em especificações implementáveis, reduzindo ambiguidades no desenvolvimento.
