# Estrutura SDD

Esta pasta concentra os artefatos de especificação do projeto.

## Organização Inicial

- `00-product-vision/`: visão do produto, proposta de valor e objetivos.
- `01-discovery/`: descoberta, personas, jornadas e regras de negócio iniciais.
- `02-requirements/`: requisitos funcionais, não funcionais e histórias de usuário.
- `03-features/`: especificações por funcionalidade.
- `04-diagrams/`: diagramas de contexto, fluxo e arquitetura conceitual.
- `05-technical-specs/`: contratos técnicos e definições implementáveis.
- `specs-templates/`: templates reutilizáveis para outros projetos.

## Como usar

1. Definir a visão do produto.
2. Organizar descobertas e contexto.
3. Formalizar requisitos.
4. Especificar cada funcionalidade.
5. Validar com diagramas e refinamentos iterativos.
