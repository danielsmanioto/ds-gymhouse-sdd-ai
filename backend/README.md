# Backend — DS Gym House

## Stack

- Java 25
- Spring Boot 3
- Spring Web
- Spring Data JPA (Hibernate)
- Spring Security
- PostgreSQL
- JWT (JJWT)

## Rodar local

1. Configure variáveis de ambiente (opcional):
   - `DB_URL`
   - `DB_USER`
   - `DB_PASSWORD`
   - `PORT`
2. Execute:
   - `./mvnw spring-boot:run` (se usar wrapper)
   - ou `mvn spring-boot:run`

## Endpoint de verificação

- `GET /api/v1/health`
